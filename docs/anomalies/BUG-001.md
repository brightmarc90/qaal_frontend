# BUG-001 — Accès au dashboard sans authentification

## Statut

Ouvert

## Criticité

Majeure

## Environnement

Local

## Fonctionnalité

Authentification / contrôle d'accès

## Précondition

L'utilisateur n'est pas authentifié.

## Étapes de reproduction

1. Ouvrir un nouveau contexte navigateur.
2. Accéder directement à `/dashboard`.

## Résultat attendu

L'utilisateur doit être redirigé vers `/login`.

## Résultat observé

Le dashboard est accessible sans authentification.

## Test associé

TC-AUTH-003

## Reproductibilité

100 %

## Impact

Un utilisateur non authentifié peut accéder à une page normalement protégée.
